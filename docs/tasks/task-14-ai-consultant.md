# Задача 14: ИИ-консультант

## Статус: ✅ Выполнено

---

## Описание
Всплывающий чат-виджет с ИИ-консультантом на основе OpenAI GPT. Включается/выключается и настраивается из Admin.

---

## UI виджет

### Внешний вид
- Круглая кнопка в правом нижнем углу (64×64 px)
- Иконка: 🔥 или аватар бота
- При клике — открывается чат-окно (350×500 px)
- Заголовок чата: "Огонёк — консультант"
- Приветственное сообщение автоматически

### Анимации
- Кнопка: пульсирующий ring (glow анимация)
- Открытие: slide-up + fade-in
- Сообщения: fade-in каждое
- "Печатает...": три точки анимация

## Системный промпт (по умолчанию)

```
Ты — консультант Charcoal Shop, компании по продаже профессиональных угольных брикетов Pini Kay.

Ты помогаешь владельцам и менеджерам ресторанов, кафе, шаурмичных и других заведений:
- Выбрать подходящий объём и вид угля
- Рассчитать потребность (расход на смену/месяц)
- Ответить на вопросы по использованию и хранению
- Объяснить преимущества Pini Kay vs обычный уголь
- Помочь оформить заявку

Продукты:
1. Угольные брикеты Pini Kay 10 кг — 890 ₽ (опт от 750 ₽)
2. Угольные брикеты Pini Kay 20 кг — 1590 ₽ (опт от 1350 ₽)
3. Парафиновый розжиг 8 шт — 120 ₽

Ключевые факты:
- Горение до 8 часов
- Температура 900°C
- 1 кг = 7 кг обычного угля
- Нет дыма, запаха, копоти
- Подходит для: хоспер, мангал, камадо, гриль
- Розжиг за 15-20 минут

Для оформления заявки направляй на: /order
Для расчёта расхода используй: 1.5-2 кг/хоспер/смена (4-6 ч)

Отвечай кратко, профессионально, по-русски. Если вопрос не связан с нашей продукцией или ресторанным делом — мягко перенаправь к теме.
```

## Настройки в Admin

```
Настройки → ИИ-консультант:
- Включён: toggle (true/false)
- Имя бота: "Огонёк"
- Приветствие: "Привет! Я Огонёк — консультант по углю. Чем могу помочь?"
- Системный промпт: textarea (большой)
- Модель: select (gpt-4o-mini / gpt-4o)
- Температура: slider 0-1 (default 0.7)
- Max tokens: number (default 500)
- Аватар: загрузка изображения
- Тест: встроенный чат для проверки настроек
```

## Backend API

```typescript
// POST /api/v1/ai/chat
interface AiChatRequest {
  messages: { role: 'user' | 'assistant'; content: string }[]
  sessionId?: string  // для истории в рамках сессии
}

interface AiChatResponse {
  reply: string
  sessionId: string
}

// Ограничения:
// - max 30 сообщений/час с одного IP
// - max 10 сообщений в истории (sliding window)
// - max 500 токенов в ответе
// - фильтр запрещённого контента
```
