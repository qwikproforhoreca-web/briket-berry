## Описание
Многошаговая форма заявки с выбором продуктов, объёма, способа оплаты (ЮКасса / Счёт), контактными данными и подтверждением.

---

## Шаги формы

### Шаг 1: Выбор продуктов
- Pini Kay 10 кг — количество ящиков (input)
- Pini Kay 20 кг — количество ящиков (input)
- Розжиг 8 шт. — количество упаковок (input)
- Автоматический расчёт стоимости
- Прогресс-бар: Шаг 1 из 3

### Шаг 2: Выбор способа оплаты
Два варианта в виде красивых карточек:

**Вариант А — Онлайн оплата (ЮКасса)**
- Иконка: карта с лого ЮКасса
- Подпись: «Оплата картой, СБП, QR-кодом»
- Преимущество: «Моментальная обработка заказа»
- Логотипы: Visa, MasterCard, МИР, СБП

**Вариант Б — Счёт для юрлиц**
- Иконка: документ/счёт
- Подпись: «Выставляем счёт на вашу организацию»
- Преимущество: «Для ООО и ИП с НДС/без НДС»
- Поля: ИНН (опционально для автозаполнения)

### Шаг 3: Контактные данные
**Поля:**
- Имя* (текст, 2-50 символов)
- Телефон* (формат +7 (XXX) XXX-XX-XX)
- Email (email формат)
- Название заведения*
- Тип заведения (select: ресторан / кафе / шаурмичная / доставка / другое)
- Город* (текст)
- Комментарий (textarea, до 500 символов)
- Согласие с политикой конфиденциальности (checkbox, обязательное)

**Для Счёт дополнительно:**
- ИНН (10 или 12 цифр)
- Название организации (автозаполнение по ИНН через API ФНС)
- ФИО директора
- Юридический адрес

## Валидация (Zod схемы)

```typescript
const orderSchema = z.object({
  // Продукты
  piniKay10kg: z.number().min(0).max(999),
  piniKay20kg: z.number().min(0).max(999),
  firestarters8: z.number().min(0).max(999),
  
  // Должен быть хотя бы 1 товар
  total: z.number().positive('Выберите хотя бы один товар'),
  
  // Оплата
  paymentMethod: z.enum(['online', 'invoice']),
  
  // Контакты
  name: z.string().min(2, 'Минимум 2 символа').max(50),
  phone: z.string().regex(/^\+7\s?\(?\d{3}\)?\s?\d{3}[-\s]?\d{2}[-\s]?\d{2}$/, 
    'Неверный формат телефона'),
  email: z.string().email('Неверный email').optional().or(z.literal('')),
  establishment: z.string().min(2).max(100),
  establishmentType: z.enum(['restaurant', 'cafe', 'shawarma', 'delivery', 'other']),
  city: z.string().min(2).max(50),
  comment: z.string().max(500).optional(),
  privacyConsent: z.literal(true, {
    errorMap: () => ({ message: 'Необходимо согласие' })
  }),
  
  // Для счёта (опционально)
  inn: z.string().regex(/^\d{10}(\d{2})?$/).optional(),
  organizationName: z.string().max(200).optional(),
  directorName: z.string().max(100).optional(),
  legalAddress: z.string().max(300).optional(),
})
```

## Безопасность формы

1. **Rate limiting**: не более 5 заявок с одного IP в час
2. **CAPTCHA**: reCAPTCHA v3 (невидимая)
3. **Honeypot поле**: скрытое поле `website` — если заполнено, это бот
4. **Sanitization**: DOMPurify для всех текстовых полей
5. **CSRF токен**: на каждую сессию
6. **Телефон**: нормализация и валидация формата
7. **XSS защита**: экранирование HTML спецсимволов

## После отправки формы

### Успешная отправка (онлайн оплата)
1. Создаётся заказ в БД со статусом `pending_payment`
2. Создаётся платёж в ЮКасса
3. Редирект на страницу оплаты ЮКасса
4. После оплаты → редирект на `/order/success`
5. Email с подтверждением отправляется клиенту
6. Email-уведомление отправляется менеджеру

### Успешная отправка (счёт)
1. Создаётся заказ в БД со статусом `awaiting_invoice`
2. Генерируется PDF счёт (опционально)
3. Email со счётом отправляется клиенту
4. Email-уведомление менеджеру
5. Редирект на `/order/success` с сообщением о счёте

### Страница `/order/success`
- Анимация успеха (огонь/звёзды)
- «Ваша заявка принята! Номер: #XXXX»
- «Мы свяжемся с вами в течение 30 минут»
- Для счёта: «Счёт отправлен на email»
- Кнопки: «На главную» | «Посмотреть заказ»
