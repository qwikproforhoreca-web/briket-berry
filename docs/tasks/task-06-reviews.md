## Структура компонента ReviewCard

```typescript
interface Review {
  id: string;
  name: string;
  position: string;
  company: string;
  city: string;
  rating: number;        // 1-5
  text: string;
  date: string;
  photo: string;         // URL фото
  verified: boolean;     // Подтверждённый клиент
  featured: boolean;     // Показывать в превью
}
```

## Анимации

## Admin функции

В админ-панели для каждого отзыва:
- Добавить/редактировать/удалить
- Выбрать «featured» (показывать на главной)
- Загрузить фото клиента
- Верифицировать (значок «проверен»)
- Одобрить/скрыть (модерация)
