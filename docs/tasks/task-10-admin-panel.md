# Задача 10: Админ-панель / CRM

## Статус: ✅ Выполнено

## URL: `/admin`

---

## Описание
Полноценная CRM-система для управления заявками, продуктами, отзывами, настройками. Защищена JWT аутентификацией.

---

## Разделы Admin

### 1. Dashboard (`/admin`)
**Виджеты:**
- Новых заявок сегодня (number)
- Выручка за месяц (number, ₽)
- Конверсия заявок (% оплаченных)
- Всего клиентов (unique phone)

**Графики:**
- Заявки по дням (last 30 days) — Bar chart
- Распределение по городам — Pie chart
- Статусы заявок — Donut chart
- Выручка по месяцам — Line chart

**Последние заявки** (таблица, 10 строк):
- № заявки | Клиент | Заведение | Сумма | Статус | Дата | Действия

**Уведомления** (список):
- Новые заявки
- Статусы оплат

---

### 2. Заявки (`/admin/orders`)
**Список заявок:**
- Поиск по имени, телефону, номеру заявки
- Фильтр по статусу, городу, типу оплаты, дате
- Сортировка по дате, сумме

**Таблица колонки:**
- Чекбокс | № заявки | Клиент | Телефон | Заведение | Город | Сумма | Способ оплаты | Статус | Дата | Действия

**Действия над заявкой:**
- Просмотр деталей (модальное окно)
- Смена статуса (dropdown)
- Пометить как «важная»
- Удалить
- Написать в WhatsApp (ссылка wa.me)

**Детали заявки (modal/страница):**
- Полная информация о клиенте
- Список товаров
- История изменений статуса
- Комментарии менеджера (добавить заметку)
- Статус оплаты

**Экспорт:**
- CSV: выбрать поля + период
- Excel (опционально)
- Поля: имя, телефон, email, заведение, город, товары, сумма, статус, дата

---

### 3. Продукты (`/admin/products`)
**Список продуктов:**
- Фото | Название | SKU | Цена | Опт. цена | Категория | В наличии | Действия

**Форма создания/редактирования продукта:**
- Название
- Slug (авто-генерация + редактирование)
- Описание (rich text editor — TipTap)
- Краткое описание
- Цена (розничная)
- Оптовая цена + min количество для опта
- Вес (кг)
- SKU
- В наличии (toggle)
- Категория (select)
- Изображения (множественная загрузка, drag & drop)
- Характеристики (key-value редактор)
- Порядок сортировки

---

### 4. Отзывы (`/admin/reviews`)
**Список отзывов:**
- Фото | Имя | Заведение | Рейтинг | Опубликован | Featured | Дата | Действия

**Форма отзыва:**
- Имя клиента
- Должность
- Компания / заведение
- Город
- Рейтинг (1-5 звёзд)
- Текст отзыва
- Фото (загрузка)
- Опубликован (toggle)
- Featured (toggle) — показывать на главной
- Верифицирован (toggle)
- Порядок сортировки

**Модерация:**
- Быстрые кнопки: Опубликовать / Скрыть
- Bulk actions: Опубликовать выбранные

---

### 5. Настройки (`/admin/settings`)

**Вкладки:**

#### Общее
- Название сайта
- Телефон (основной)
- WhatsApp
- Telegram
- Email
- Адрес

#### Видео
- **Фоновое видео** (Hero): загрузка MP4 / ссылка URL
  - Предпросмотр текущего видео
  - Кнопка загрузки нового
  - Прогресс загрузки
- **Видео-инструкция**: загрузка / ссылка
  - Превью
  - Замена

#### ИИ-консультант
- Включить/выключить (toggle)
- Имя бота
- Аватар бота (загрузка)
- Системный промпт (textarea)
- Приветственное сообщение
- Модель (gpt-4o-mini / gpt-4o)
- Температура (slider 0-1)
- Max tokens (число)
- Тест чата (встроенный)

#### SEO
- Title шаблон
- Description шаблон
- Keywords
- OG Image (загрузка)
- Robots.txt (textarea)

#### Оплата
- ЮКасса Shop ID
- ЮКасса Secret Key (masked)
- Тестовый режим (toggle)
- Return URL
- Email для уведомлений о платежах

#### Email
- SMTP хост
- SMTP порт
- Пользователь
- Пароль (masked)
- От кого (name + email)
- Email менеджера для уведомлений
- Тест отправки

## Дизайн Admin

- **Тема**: тёмная (dark mode) — соответствует основному сайту

- **Таблицы**: sticky header, pagination (20 записей)
- **Уведомления**: toast notifications (success/error/info)
- **Загрузка**: skeleton screens
