# SEO Playbook: briket-berry.ru (RU, Россия)

Цель: лиды/заявки/продажи по коммерческим запросам про брикетный уголь для мангалов, хосперов и профессиональной кухни.

## 1) SEO-стратегия и семантика

### Кластеры по интентам

- Коммерческие (BOFU): купить, цена, опт, поставщик, для ресторана/кафе/хоспера.
- Информационные (TOFU/MOFU): как разжечь, сколько горит, что лучше уголь или брикеты, как хранить.
- Навигационные: брендовые запросы и переходы на конкретные разделы сайта.

### Частотность

- High: `угольные брикеты купить`, `брикеты pini kay`, `уголь для мангала`.
- Mid: `уголь для хоспера`, `брикеты для ресторана оптом`, `парафиновый розжиг купить`.
- Low/long-tail: `угольные брикеты для хоспера оптом москва`, `сколько горят брикеты pini kay`, `бездымный уголь для шаурмы`.

### Антиканнибализация

- `/products` — только каталог и коммерческие «купить/цена/опт».
- `/comparison` — только сравнение с обычным углем.
- `/how-to-use` — инструкции/FAQ/гайды.
- `/firestarters` — отдельный кластер розжига.
- `/reviews` — социальное доказательство и бренд-траст.

## 2) Silo architecture

- `/about` О компании

- `/prices` Прайс и условия поставки
- `/faq` Вопросы и ответы (отдельный хаб)
- `/blog` Блог/база знаний
- `/contacts` Контакты + NAP

## 3) Контент под ранжирование (EEAT)

### Коммерческие страницы (структура)

1. Проблема: нестабильный жар, дым, высокий расход.
2. Решение: брикеты Pini Kay и розжиг.
3. Выгоды: дольше горение, меньше расход, чище кухня.
4. Доказательства: кейсы, отзывы, сравнения, цифры.
5. CTA: заявка, звонок, расчет объема.

### EEAT-блоки (обязательные)

- Авторство материалов (эксперт по хосперам/грилю).
- Опыт: кейсы заведений, сроки сотрудничества.
- Доверие: отзывы, сертификаты, реквизиты.
- Прозрачность: условия оплаты/доставки/возврата.

## 5) Техническое SEO

Внедрено в проект:

- `frontend/public/robots.txt`
- `frontend/public/sitemap.xml`
- canonical + robots + OG для ключевых страниц
- JSON-LD в `HomePage`, `HowToUsePage`, `ReviewsPage`
- `noindex` для `/admin`, `404`, `order/success`

### Core Web Vitals target

- LCP < 2.5s: preconnect, оптимизация hero-медиа, webp/avif.
- CLS < 0.1: фиксированные размеры медиа/контейнеров.
- INP < 200ms: меньше тяжелых JS-обработчиков, lazy-load секций.

### Доступность и семантика

- Один H1 на страницу.
- Иерархия H2/H3 без скачков.
- Alt для всех контентных изображений.
- Контраст текста >= WCAG AA.

## 6) Локальное SEO (Россия)

### Гео-ядро

- Россия (федеральный охват), приоритет: Москва, Санкт-Петербург, Казань, Екатеринбург, Новосибирск.

### NAP (единый формат)

- Name: Брикет-Бери
- Address: Россия (указать фактический адрес склада/офиса после финализации)
- Phone: +7-900-000-00-00 (заменить на рабочий)

### Google Business Profile / Яндекс Бизнес

- Категории: поставщик угля, оптовый поставщик топлива для HoReCa.
- Фото: склад, упаковка, отгрузки, кейсы ресторанов.
- Посты: кейсы, сезонные офферы, доставка.

## 8) Конверсия + UX

- Первый экран: оффер + 1 главный CTA + 1 вторичный CTA.
- Формы: минимум полей, пошаговая логика, явные подсказки.
- Доверие рядом с CTA: отзывы, кейсы, «500+ клиентов», гарантии.
- Mobile-first: кнопка заявки и звонка в зоне быстрого доступа.

## План внедрения 30/60/90

### 30 дней
- Технический SEO baseline (robots, sitemap, canonical, OG, schema).
- Устранение дублей мета-тегов.
- Настройка GSC + Яндекс Вебмастер + Метрика + GA4.

### 60 дней
- Запуск `/about`, `/cases`, `/prices`, `/contacts`.
- Публикация 8-12 статей по TOFU/MOFU.
- Внутренняя перелинковка по silo.

### 90 дней
- Доработка локальных посадочных страниц по городам.
- Расширение FAQ и review schema.
- A/B тест офферов и форм на `/order`.

## Чеклист измерения эффективности

- Позиции по primary и long-tail ключам (Google/Yandex).
- CTR из поиска по ключевым страницам.
- Индексация (coverage, excluded, canonical issues).
- Core Web Vitals (CrUX + Lighthouse).
- Конверсии: заявки, звонки, переходы в мессенджеры.
- CPL/лид и доля органики в выручке.
