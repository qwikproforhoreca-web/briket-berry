# Исправление запуска Kingdom Come: Deliverance II

Скрипт автоматически применяет типичные исправления, когда **лаунчер или игра KCD2 не запускается**.

## Быстрый старт (Windows)

**Один клик — всё сам:**

1. Скачайте папку `tools/kcd2-launcher-fix` на свой ПК.
2. Дважды щёлкните **`Launch-KCD2-All.bat`**.
3. Подтвердите права администратора.
4. Скрипт сам: починит файлы → откроет Steam/Epic → запустит игру.

Альтернатива (только исправление без запуска): **`Fix-KCD2Launcher.bat`**

## Что делает скрипт

- Останавливает конфликтующие процессы (Riot Vanguard, оверлеи и т.д.)
- Удаляет кэш шейдеров (`Saved Games\kingdomcome2\shaders`)
- Устанавливает Microsoft Visual C++ Redistributable (x64 и x86)
- Добавляет папку игры в исключения Windows Defender
- Проверяет наличие `WHGame.dll` и `KingdomCome.exe`
- Запускает проверку целостности файлов в Steam (AppID 1771300)
- Выполняет `sfc /scannow` и `DISM /RestoreHealth`

## Дополнительные параметры

Запуск из PowerShell (от администратора):

```powershell
# Без переустановки VC++ и без SFC/DISM (быстрее)
.\Fix-KCD2Launcher.ps1 -SkipVcRedist -SkipSystemRepair

# Запустить игру сразу после исправлений
.\Fix-KCD2Launcher.ps1 -LaunchAfterFix
```

## Если всё ещё не запускается

1. Убедитесь, что игра установлена **на SSD** (на HDD часто не стартует).
2. В Steam: **Свойства игры → Общие → Параметры запуска** — очистите поле полностью.
3. Первый запуск: **оконный режим**, графика **Средняя**, сглаживание **выкл**.
4. Обновите драйвер видеокарты (лучше чистая установка через DDU).
5. Полная переустановка: удалите игру, удалите папки вручную, установите заново на SSD.

## Требования

- Windows 10/11 (64-bit)
- Права администратора
- Интернет (для скачивания VC++ Redistributable)
